# CourseSniffer 实验 1A 自动演示与录屏说明

在 **macOS 图形桌面**上，双击项目根目录的 `运行完整演示并录屏.command`，或者在 Terminal 中执行：

```bash
bash scripts/record_demo_macos.sh
```

脚本检查 Command Line Tools 与 Homebrew，自动安装缺少的 `qtbase`、`cmake`、`ninja` 和 `ffmpeg`，构建 Qt 程序并运行 CTest。只有测试通过后才会请求管理员授权，临时调整 BPF 字符设备的读取权限，并以当前普通用户身份启动 CourseSniffer。权限管理程序负责关闭后恢复原有设备属性。输入系统要求的 sudo 密码后，不需要操作鼠标或手工输入过滤条件。录制期间保持 Mac 的图形桌面会话正常运行。

## 视频实际展示内容

1. 启动 CourseSniffer 并选择 `lo0`；实际通过 libpcap 抓包。
2. 自动运行 `demo/run_demo.py`，生成真实 IPv4/IPv6 HTTP 请求、响应和 UDP 回声报文。
3. 停止实时捕获，选中数据包，展示协议字段及原始字节。
4. 输入并执行 `ip.addr == 127.0.0.1 and tcp`，展示地址与协议组合过滤。
5. 输入并执行 `http and tcp.port == 8080`、`ipv6 and (tcp or udp)` 和 UDP 过滤表达式。
6. 选择一条实际捕获的 IPv4 HTTP 连接，展示两个 TCP 方向的内容。
7. 加载 `demo/protocol_examples.pcap`，展示 DNS 和 ARP 的解析字段。**这一段在程序界面、画面来源标签及字幕中明确标为离线样例。**
8. 结束演示，等待视频编码器正常关闭。

录制器从当前 Qt 窗口连续取得画面，使用 FFmpeg 编码为 H.264 MP4；内容窗口以合成方式显示在同一画面中，字幕由 Qt 绘制在视频底部。录制仅包含 CourseSniffer 窗口，不捕获整个桌面或其他应用。整个过程无需授予 macOS 的全屏录制权限。

## 文件位置

脚本输出到项目根目录的 `recordings`：

- `仲泓宇_202618013229068_ex1A_play.mp4`：包含实际 GUI 连续画面与嵌入式中文字幕的视频。
- 同名前缀的 `.srt`：可以编辑的中文字幕与时间轴。
- 同名前缀的 `.proof.json`：实际抓包与编解码检查结果，包含接口、数据包数量、协议计数、视频参数和成功状态。
- 同名前缀的 `.traffic.log`：实际 HTTP/UDP 流量脚本日志。
- 同名前缀的 `.ffmpeg.log`：视频编码错误日志。

录制成功必须同时满足：目标 Mac 实时抓包接口成功激活，实际捕获 IPv4/IPv6、TCP、UDP、HTTP 报文，有可查看的 HTTP 双向 TCP 内容，完成 DNS/ARP 离线样例展示，FFmpeg 正常退出，输出 MP4、SRT 和通过状态的 JSON 记录。若检查失败，脚本会以非零状态退出，日志保留在 `recordings` 中。录制中的临时文件以 `.recording.mp4` 结尾，成功后才生成指定的视频文件。

## 运行注意事项

- 需要能访问 `127.0.0.1` 和 `::1` 的本机网络环境，以及可绑定 TCP `8080`、UDP `9999` 的空闲端口。
- 抓包属于授权课程实验，脚本只操作本机回环接口；其他网络接口的混杂模式应在本机验证阶段单独演示。
- Mac 的窗口显示和临时 BPF 权限仍依赖系统配置。脚本不将离线样例标记为真实网络流量。
- 默认输出文件名符合课程视频名称要求。视频生成后，请实际播放并检查画面、字幕、时长与课程网站上传规则。
